# Sicherheit

Diese Datei gilt für alle Repositories der Organisation **kliqtape**, die keine eigene
`SECURITY.md` haben.

## Lücken melden

Bitte **kein öffentliches Issue** für Sicherheitslücken. Melde sie stattdessen vertraulich über
GitHub: im betroffenen Repository unter **Security → Report a vulnerability**. Die Meldung sehen
nur die Maintainer.

Wir antworten in der Regel innerhalb einer Woche, halten dich auf dem Laufenden und nennen dich
gern beim Fix, wenn du das möchtest.

## Unterstützte Versionen

Sicherheitsupdates gibt es jeweils für die neueste Version auf `main`.
